# NMOS 원인 공정 추천 — 웨이퍼맵과 EDS 불량 종류로 「어느 단계부터 볼지」

종합설계 「웨이퍼 불량 지도로 원인 공정 좁히기」에서 **NMOS 부분만** 뽑아 온 공개 저장소예요.
조원 발표 준비용으로 정리했어요. 결과 숫자 전체와 근거는 [`docs/details.md`](docs/details.md)에 있어요.

## 한눈에

1. **모양** — 웨이퍼맵 → 모양 CNN → 모양 9종 중 하나 → 원인 39개 중 후보를 좁힘
2. **어느 단계** — 칩마다 EDS 불량 종류(12가지) 분포 → 후보에 순위 → 먼저 볼 공정 단계 + 확인할 장비 기록
3. **얼마나** — 웨이퍼 WAT 값 → MOS 식으로 거꾸로 → 파라미터가 얼마나 벗어났나 (예: gate 산화막 약 75 Å, 정상 53 ~ 68 Å 밖)

- **공정** — NMOS 하나를 41단계 · 마스크 6장으로 정했어요 (IDEC 0.5 µm 공정 + 소자 분리 STI + silicide 막는 층 SAB).
- **원인 표** — 단계마다 「틀어지면 웨이퍼맵이 어떤 모양이 되고, 칩이 어느 측정으로 떨어지나」를 원인 39개로 적었어요.
- **패턴만으로는 부족해요** — 「거의 전체」 모양 하나에 후보가 18개라서, 칩이 어떤 측정으로 떨어졌는지(불량 종류)를 더 봐요.

## 발표에 쓸 숫자

| 무엇 | 숫자 | 같이 말할 단서 |
|---|---|---|
| 공정 · 원인 | 41단계 · 원인 39개 · EDS 불량 종류 12가지 | |
| 모양 CNN (처음 보는 lot 1,615개 · 26,180장) | 정확도 0.907 · macro F1 0.741 | 정상 웨이퍼 22,307장 중 1,950장(8.7%)을 불량 모양으로 부름 — 긁힘이 794장 |
| 원인을 단독 1위로 짚음 (합성 시험) | 39개 중 **20개** · 정답이 3순위 안 **96%** | 상한 — 사고를 심을 때와 채점할 때 같은 원인 표를 씀 |
| 비교 — 모양만 쓰면 | 39개 중 2개 · 3순위 안 38% | 측정을 붙여야 단계가 갈림 |
| 「얼마나」 (원인 7개 × 웨이퍼 120장) | 90% 범위가 넣은 값을 담는 비율 88 ~ 94% | 합성 WAT 값 |

## 데이터 — 무엇이 실측이고 무엇이 합성인가

| 데이터 | 출처 | 실측 / 합성 |
|---|---|---|
| 웨이퍼맵 | WM-811K (Wu, Jang & Chen 2015) — 라벨 있는 맵 172,950장, Kaggle | **실측** 양산 맵 (제품 종류 · 직경 정보 없음) |
| 칩별 EDS 불량 종류 | 원인 표로 만듦 — 불량 칩마다 주 불량 50%, 나머지는 다른 칸에 고르게 | 합성 |
| WAT 값 | MOS 식 + 기준값 + 정상 산포 | 합성 |
| 공정 · 기준값 · 합격선 | IDEC 0.5 µm · KSIA 강의, MOSIS 실측, GF180MCU 공개 spec | 문헌 · 공개 자료 |

WM-811K에는 합격 / 불합격만 있어서, 「칩이 어느 측정으로 떨어졌나」는 원인 표로 합성했어요.

## 모양 CNN — 여기서 바로 돌아가요

```bash
pip install -r requirements-cnn.txt
bash scripts/download_wm811k.sh            # Kaggle API 키 필요 → data/raw/wm811k/WM811K.pkl
python scripts/a1b_lotwise_model.py         # lot 단위로 나눠 학습 → models/wafermap/wafermap_cnn_lotwise.pt
```

```python
from src.inference.wafermap_predictor import WaferMapPredictor
p = WaferMapPredictor("models/wafermap/wafermap_cnn_lotwise.pt")
p.predict(wafer_map)   # 26×26, 값 0 = 웨이퍼 밖 · 0.5 = 정상 칩 · 1.0 = 불량 칩 → 모양 · 확신도
```

가중치가 저장소에 있어서 데이터를 받지 않아도 판정은 바로 해 볼 수 있어요.
원인 표 · 합성 시험 · 시연 화면 파일은 비공개 저장소의 엔진 본체(`rootcause_kb`)를 불러서, **여기서는 읽기용**이에요.

## 한계 — 발표 때 같이 말할 것

- **칩 측정과 WAT 값은 합성이에요.** 실측은 웨이퍼맵과 CNN 판정뿐이에요.
- **합성 시험 숫자는 상한이에요.** 같은 원인 표로 문제를 내고 채점했어요.
- **CNN 오경보** — 정상 웨이퍼의 8.7%를 불량 모양으로 불러요. 확률 문턱을 두면 오경보는 약 4분의 1로 줄지만 놓치는 불량이 늘어서, 엔진에는 아직 안 붙였어요.
- **fail 근거** — 원인 39개 중 「칩이 어느 측정으로 떨어지나」를 문헌이 말하는 것은 15개(일부 1개 포함), 나머지 24개는 소자 원리로 추론했어요.

자세한 숫자 · 시연 17장 · 근거 · 참고문헌(복붙용)은 [`docs/details.md`](docs/details.md)에 있어요.
